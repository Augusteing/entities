【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "方法",
      "text": "相关分析法"
    },
    {
      "type": "部件",
      "text": "高压转子"
    },
    {
      "type": "结论",
      "text": "高压转子振动大"
    },
    {
      "type": "维修措施",
      "text": "高压转子重新平衡"
    },
    {
      "type": "指标",
      "text": "振动值"
    }
  ],
  "relations": [
    {
      "type": "得出结论",
      "head": "相关分析法",
      "tail": "高压转子振动大"
    },
    {
      "type": "降低了",
      "head": "高压转子重新平衡",
      "tail": "振动值"
    },
    {
      "type": "验证了",
      "head": "高压转子重新平衡",
      "tail": "相关分析法"
    }
  ]
}
```
