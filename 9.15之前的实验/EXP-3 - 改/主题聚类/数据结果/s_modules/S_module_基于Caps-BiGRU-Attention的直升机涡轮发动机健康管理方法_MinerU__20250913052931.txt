【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "技术",
      "text": "信息融合"
    },
    {
      "type": "融合方式",
      "text": "数据融合"
    }
  ],
  "relations": [
    {
      "type": "包括",
      "head": "信息融合",
      "tail": "数据融合"
    }
  ]
}
```

示例2：
```json
{
  "entities": [
    {
      "type": "网络",
      "text": "神经网络"
    }
  ],
  "relations": [
    {
      "type": "使用的数学工具有",
      "head": "信息融合",
      "tail": "神经网络"
    }
  ]
}
```
