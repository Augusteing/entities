【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "方法",
      "text": "半监督框架下的自标记技术和多学习器模型的结合方法"
    },
    {
      "type": "算法",
      "text": "支持向量机（SVM）"
    },
    {
      "type": "模型",
      "text": "隐马尔可夫模型（HMM）"
    }
  ],
  "relations": [
    {
      "type": "解决",
      "head": "半监督框架下的自标记技术和多学习器模型的结合方法",
      "tail": "欠标记且不平衡的垃圾网页数据集分类问题"
    }
  ]
}
```
