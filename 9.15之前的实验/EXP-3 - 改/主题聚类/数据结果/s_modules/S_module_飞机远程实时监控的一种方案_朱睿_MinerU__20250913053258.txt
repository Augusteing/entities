【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "系统",
      "text": "飞机健康管理系统"
    },
    {
      "type": "策略",
      "text": "视情维修"
    },
    {
      "type": "状态",
      "text": "健康"
    }
  ],
  "relations": [
    {
      "type": "实现...的转变",
      "head": "飞机健康管理系统",
      "tail": "视情维修"
    }
  ]
}
```
