【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "系统/部件",
      "text": "飞机液压泵"
    },
    {
      "type": "系统/部件",
      "text": "液压系统"
    }
  ],
  "relations": [
    {
      "type": "是...的关键部件",
      "head": "飞机液压泵",
      "tail": "液压系统"
    }
  ]
}
```

示例2：
```json
{
  "entities": [
    {
      "type": "方法",
      "text": "故障注入"
    },
    {
      "type": "技术",
      "text": "故障诊断"
    },
    {
      "type": "技术",
      "text": "故障预测"
    },
    {
      "type": "方法",
      "text": "故障预测方法"
    }
  ],
  "relations": [
    {
      "type": "以...为主要手段",
      "head": "健康管理",
      "tail": "故障诊断"
    },
    {
      "type": "以...为主要手段",
      "head": "健康管理",
      "tail": "故障预测"
    }
  ]
}
```
