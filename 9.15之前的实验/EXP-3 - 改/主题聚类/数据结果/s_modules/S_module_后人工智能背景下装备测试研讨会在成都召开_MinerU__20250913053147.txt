【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "系统",
      "text": "特种飞机综合化任务系统PHM"
    },
    {
      "type": "系统",
      "text": "综合化任务系统"
    }
  ],
  "relations": [
    {
      "type": "针对",
      "head": "特种飞机综合化任务系统PHM",
      "tail": "综合化任务系统"
    }
  ]
}
```

示例2：
```json
{
  "entities": [
    {
      "type": "特征",
      "text": "综合化"
    }
  ],
  "relations": [
    {
      "type": "发展方向为",
      "head": "航空电子系统",
      "tail": "综合化"
    }
  ]
}
```

示例3：
```json
{
  "entities": [
    {
      "type": "系统/部件",
      "text": "飞机液压泵"
    },
    {
      "type": "系统/部件",
      "text": "液压系统"
    }
  ],
  "relations": [
    {
      "type": "是...的关键部件",
      "head": "飞机液压泵",
      "tail": "液压系统"
    }
  ]
}
```
