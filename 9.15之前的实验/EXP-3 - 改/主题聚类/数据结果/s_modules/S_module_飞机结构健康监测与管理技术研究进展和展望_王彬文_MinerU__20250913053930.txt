【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "评估阶段",
      "text": "二级评估"
    },
    {
      "type": "因子",
      "text": "惩罚因子"
    }
  ],
  "relations": [
    {
      "type": "引入",
      "head": "二级评估",
      "tail": "惩罚因子"
    }
  ]
}
```

示例2：
```json
{
  "entities": [
    {
      "type": "产品",
      "text": "航空产品"
    },
    {
      "type": "技术",
      "text": "传感"
    },
    {
      "type": "技术",
      "text": "微机电系统（MEMS）传感技术"
    },
    {
      "type": "技术",
      "text": "产品全生命周期健康管理"
    }
  ],
  "relations": [
    {
      "type": "奠定了技术基础",
      "head": "微机电系统（MEMS）传感技术",
      "tail": "产品全生命周期健康管理"
    }
  ]
}
```
