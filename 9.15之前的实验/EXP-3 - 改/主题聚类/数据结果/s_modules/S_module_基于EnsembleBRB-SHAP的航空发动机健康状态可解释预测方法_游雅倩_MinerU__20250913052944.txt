【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "数据",
      "text": "多源异构数据"
    },
    {
      "type": "系统/部件",
      "text": "飞机"
    },
    {
      "type": "系统/部件",
      "text": "发动机"
    },
    {
      "type": "概念",
      "text": "数据融合"
    },
    {
      "type": "网络",
      "text": "双向循环神经网络"
    }
  ],
  "relations": [
    {
      "type": "产生",
      "head": "飞机",
      "tail": "多源异构数据"
    },
    {
      "type": "分为四个阶段",
      "head": "数据融合",
      "tail": "数据融合"
    }
  ]
}
```
