【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "系统/部件",
      "text": "航空蓄电池"
    },
    {
      "type": "系统/部件",
      "text": "锂离子航空蓄电池"
    }
  ],
  "relations": [
    {
      "type": "作为...的典型代表",
      "head": "锂离子航空蓄电池",
      "tail": "航空电子产品"
    }
  ]
}
```

示例2：
```json
{
  "entities": [
    {
      "type": "实验对象",
      "text": "锂离子电池"
    },
    {
      "type": "数据集",
      "text": "美国航空航天局的4组锂离子电池数据"
    }
  ],
  "relations": [
    {
      "type": "采用",
      "head": "实验",
      "tail": "美国航空航天局的4组锂离子电池数据"
    }
  ]
}
```
