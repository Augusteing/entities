【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "研究对象",
      "text": "航空发动机滑油系统"
    },
    {
      "type": "软件/平台",
      "text": "Simulink"
    },
    {
      "type": "模型",
      "text": "滑油系统模型"
    }
  ],
  "relations": [
    {
      "type": "搭建于",
      "head": "滑油系统模型",
      "tail": "Simulink"
    }
  ]
}
```

示例2：
```json
{
  "entities": [
    {
      "type": "系统",
      "text": "航空发动机健康管理系统"
    },
    {
      "type": "系统",
      "text": "健康管理系统"
    }
  ],
  "relations": [
    {
      "type": "成为...重要组成部分",
      "head": "气路故障诊断",
      "tail": "健康管理系统"
    }
  ]
}
```
