【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "研究方法",
      "text": "基于多模型融合的航空电子产品故障预测方法"
    },
    {
      "type": "问题",
      "text": "航空电子产品故障预测"
    }
  ],
  "relations": [
    {
      "type": "提出用于解决",
      "head": "基于多模型融合的航空电子产品故障预测方法",
      "tail": "航空电子产品故障预测"
    }
  ]
}
```

示例2：
```json
{
  "entities": [
    {
      "type": "方法",
      "text": "故障注入"
    },
    {
      "type": "技术",
      "text": "故障诊断"
    },
    {
      "type": "技术",
      "text": "故障预测"
    },
    {
      "type": "方法",
      "text": "故障预测方法"
    }
  ],
  "relations": [
    {
      "type": "以...为主要手段",
      "head": "健康管理",
      "tail": "故障诊断"
    },
    {
      "type": "以...为主要手段",
      "head": "健康管理",
      "tail": "故障预测"
    }
  ]
}
```
