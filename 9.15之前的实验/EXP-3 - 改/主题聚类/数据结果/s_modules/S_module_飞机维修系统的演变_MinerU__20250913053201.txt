【S：Few-Shot动态采样】
以下示例均为与待抽取文本语义最相关的标注（不展示原段落），每个示例同时包含实体与关系字段：

示例1：
```json
{
  "entities": [
    {
      "type": "飞机类型",
      "text": "高复合材料飞机"
    },
    {
      "type": "飞机类型",
      "text": "全金属飞机"
    },
    {
      "type": "材料",
      "text": "复合材料"
    }
  ],
  "relations": [
    {
      "type": "转变方向为",
      "head": "全金属飞机",
      "tail": "高复合材料飞机"
    }
  ]
}
```
