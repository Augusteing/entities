## Schema参考模式
以下是从历史文献中提取的语义模式，请优先参考但不必严格限制。每个模式包含语义模板、实体类型约束、关系类型和历史频次：

### 高置信度模式（频次≥4）

**模式1：研究方法 → 包含 → 研究方法**
- **语义模板**："研究方法 → 包含 → 研究方法"
- **主语类型**：研究方法
- **关系**：包含
- **宾语类型**：研究方法
- **频次**：4
- **示例**：
  - "健康管理技术" → 包含 → "故障诊断技术"
  - "系统正向设计流程" → 包含 → "功能分配"
- **语义说明**：技术/方法的层次包含关系

**模式2：研究方法 → 结合 → 研究方法**
- **语义模板**："研究方法 → 结合 → 研究方法"
- **主语类型**：研究方法
- **关系**：结合
- **宾语类型**：研究方法
- **频次**：4
- **示例**：
  - "故障诊断技术" → 结合 → "动力学分析"
  - "数模联动" → 结合 → "机器学习方法"
- **语义说明**：不同技术的融合应用

**模式3：系统/部件 → 具有核心功能 → 应用场景**
- **语义模板**："系统/部件 → 具有核心功能 → 应用场景"
- **主语类型**：系统/部件
- **关系**：具有核心功能
- **宾语类型**：应用场景
- **频次**：4
- **示例**：
  - "健康管理系统" → 具有核心功能 → "故障预测"
  - "健康管理系统" → 具有核心功能 → "状态监测"
- **语义说明**：系统功能描述

## 模式使用指导

1. **优先匹配**：当识别到符合上述模式的实体组合时，优先考虑对应的关系类型
2. **类型约束**：严格遵守主语类型和宾语类型的约束条件
3. **频次权重**：频次越高的模式，置信度越高
4. **灵活扩展**：如发现新的合理关系，可以抽取但需标注为新模式
5. **上下文验证**：始终结合具体的文本上下文判断关系的合理性
